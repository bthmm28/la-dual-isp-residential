## 双ISP家宽VPS 到底是什么

这三个词被混用得最厉害：原生 IP、住宅 IP、双 ISP。

原生 IP 说的是 IP 的注册地和机房的物理位置对得上。洛杉矶机房开出来的 IP，在 WHOIS 数据库里国家是美国，这就叫原生。它解决的是“IP 显示在香港、服务器却在美国”这种地理错位。

住宅 IP 说的是这个 IP 归谁用。归属 ASN 是 Comcast、AT&T、中华电信这种民用宽带运营商，就是住宅 IP；归属 ASN 是 Linode、Vultr 这类 IDC 运营商，就是机房 IP。同样一台洛杉矶机器，IP 可以既是原生又是机房属性，这两件事不冲突。

双 ISP 说的是同一个 IP 在两个不同的民用 ISP 名下都有注册记录。常见组合是美国 Comcast 加 Charter 这种。它的意义在于：平台封 IP 往往是按段批量标记的，一个 ISP 的段被标记了，另一个 ISP 的段还在，账号不至于一夜之间全掉。

六六云的产品命名刚好把这四档摆了一遍，看名字就能对上号：

- “美国家宽IP - AT&T”，这是真家宽，IP 归 AT&T 的民用宽带段。
- “美西原生IP双ISP”系列，原生加双 ISP 属性，做账号业务的主力。
- “美国原生IP三网CN2 GIA大带宽”，官网写得很直白：“不保证 ISP 属性”。原生 IP，但属性偏机房。
- “美国双向4837优化”，官网注明“非 ISP 住宅 IP”。就是纯机房 IP，别拿它跑 TikTok。

这里有个最常见的误解得点破：**双 ISP 不是给你两个 IP**。它指的是同一个 IP 在两个 ISP 名下都有注册记录，跟“分配两个 IPv4”是两码事。六六云这些套餐默认都只给 1 个 IPv4。

平台为什么在意这个？TikTok、亚马逊、Netflix、ChatGPT 的风控系统会查 IP 的 ASN 归属。机房 IP 在数据库里就是“机房流量”，轻则限流重则封号。家宽 IP 看起来和普通美国家庭的宽带没区别，可信度高一个档次。

代价也很实在。家宽 IP 的价格比同配置的机房 VPS 贵，带宽还更小，因为家宽线路本身跑不到机房那种 Gbps 级别。

## 常见问题

### 双ISP是不是给两个IP？

不是。双 ISP 指的是同一个 IP 在两个不同的民用 ISP 名下都有注册记录，不是分配两个不同的 IPv4。六六云这些套餐默认都只给 1 个 IPv4，需要多 IP 得另外想办法。
